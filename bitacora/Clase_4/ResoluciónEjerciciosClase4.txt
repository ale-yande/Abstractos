EJERCICIO 2 - Contar elementos sin modificar la pila (10 puntos)
Implementá el siguiente método externo:
static int cantidadElementos(PilaTDA p)
Debe devolver la cantidad de elementos almacenados en p. La pila debe quedar exactamente igual al
finalizar. Usá solamente operaciones del TDA Pila. Ejemplo: base -> 4 -> 8 -> 2 -> 6 -> tope => retorna 4 y la pila queda sin cambios.

Método aplicado:

public static int cantidadElementos(PilaTDA pila) {
        PilaTDA aux = new Estrategia_1();
        aux.InicializarPila();
        int contador = 0;

        while (!pila.PilaVacia()){
            aux.Apilar(pila.Tope());
            pila.Desapilar();
            contador+=1;
        }

        while (!aux.PilaVacia()){
            pila.Apilar(aux.Tope());
            aux.Desapilar();
        }

        return contador;
    }


EJERCICIO 3 - Buscar un elemento sin modificar la pila (10 puntos)
Implementá:
static boolean contiene(PilaTDA p, int x)
Debe retornar true si x aparece en la pila y false en caso contrario. La pila debe quedar intacta al
finalizar. Usá solamente operaciones del TDA Pila. Además, explicá brevemente por qué necesitás una estructura auxiliar para resolverlo.

Método que aplicamos:

public static boolean contiene(PilaTDA pila, int x) {
        boolean encontrado = false;
        PilaTDA aux = new Estrategia_1();
        aux.InicializarPila();


        while (!pila.PilaVacia()) {
            if (pila.Tope()==x){
                encontrado = true;
            }
            aux.Apilar(pila.Tope());
            pila.Desapilar();
        }

        while (!aux.PilaVacia()){
            pila.Apilar(aux.Tope());
            aux.Desapilar();
        }

        return encontrado;
    }

EJERCICIO 5 - Sumar los elementos de una cola conservando el orden
(10 puntos)
Implementá:
static int sumar(ColaTDA c)
Debe retornar la suma de todos los elementos. La cola debe conservar todos sus elementos y el mismo
orden original. Ejemplo: Primero -> 3 -> 8 -> 4 -> 10 -> último => retorna 25. 

Metodo que aplicamos:
public static int sumar(ColaTDA cola){
        int contador=0;
        ColaTDA aux = new ColaEstatica();
        aux.InicializarCola();

        while (!cola.ColaVacia()){
            contador=contador+cola.Primero();
            aux.Acolar(cola.Primero());
            cola.Desacolar();
        }

        while (!aux.ColaVacia()){
            cola.Acolar(aux.Primero());
            aux.Desacolar();
        }
        return contador;
    }


EJERCICIO 6 - Eliminar todas las apariciones de un valor (12 puntos)
Implementá:
static void eliminar(ColaTDA c, int x)
Debe eliminar de la cola todas las apariciones de x, preservando el orden relativo del resto de los
elementos. Usá solamente operaciones del TDA Cola. Ejemplo: Primero -> 8 -> 3 -> 5 -> 3 -> 9 -> 3 -> último; al ejecutar eliminar(c,3), debe quedar Primero ->
8 -> 5 -> 9 -> último.

Método que aplicamos:
static void eliminar(ColaTDA cola, int x) {

        ColaTDA aux = new ColaEstatica();
        aux.InicializarCola();

        while (!cola.ColaVacia()) {
            if (cola.Primero()!=x){
                aux.Acolar(cola.Primero());
            }
            cola.Desacolar();
        }

        while (!aux.ColaVacia()){
            cola.Acolar(aux.Primero());
            aux.Desacolar();
        }
    }

exactamente igual al finalizar. Usá solamente las operaciones públicas del TDA. 

Método que aplicamos:

    static int contar(ColaPrioridadTDA cola, int x) {
        int contador=0;
        ColaPrioridadTDA aux = new ColaPrioridadEstatica();
        aux.InicializarColaPrioridad();

        while (!cola.ColaVacia()) {
            if (cola.Prioridad() == x) {
                contador++;
            }
            aux.AcolarPrioridad(cola.Primero(), cola.Prioridad());
            cola.Desacolar();

        }

        while (!aux.ColaVacia()) {
            cola.AcolarPrioridad(aux.Primero(), aux.Prioridad());
            aux.Desacolar();
        }

        return contador;
    }
